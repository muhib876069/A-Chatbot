About FunBot

FunBot is an intelligent Python chatbot that can detect user emotions and respond accordingly. It uses natural language processing to understand your mood and provides appropriate responses, jokes, and interesting facts.

The bot integrates with multiple free APIs to fetch real-time jokes and facts, making every conversation unique and engaging.

Key Features

😊 Emotion Detection

Detects user emotions (happy, sad, angry, neutral) based on keywords in the conversation.

😂 Joke Generator

Fetches random jokes from multiple APIs to keep the conversation fun and engaging.

📚 Fact Provider

Shares interesting facts from various sources including cat facts, dog facts, and useless facts.

💬 Conversation History

Maintains a history of conversations with timestamps and mood tracking.

🔗 API Integration

Integrates with multiple free APIs for dynamic content without any API keys required.

🐍 Pure Python

Built entirely in Python with no external dependencies beyond the requests library.

class EmotionalChatbot:
    def __init__(self):
        self.name = "FunBot"
        self.mood = "happy"

        self.user_mood = "neutral"

        # Emotional keyword dictionaries
        self.sad_words = ["sad", "unhappy", "depressed", "crying", "hurt", "upset"]
        self.happy_words = ["happy", "joyful", "excited", "glad", "cheerful", "great"]
        self.angry_words = ["angry", "mad", "furious", "hate", "annoyed", "irritated"]

    def detect_emotion(self, text):
        # Emotion detection logic
        text_lower = text.lower()
        
        sad_count = sum(1 for word in self.sad_words if word in text_lower)
        happy_count = sum(1 for word in self.happy_words if word in text_lower)
        angry_count = sum(1 for word in self.angry_words if word in text_lower)
        
        if sad_count > happy_count and sad_count > angry_count:
            return "sad"
        elif happy_count > sad_count and happy_count > angry_count:
            return "happy"
        elif angry_count > sad_count and angry_count > happy_count:
            return "angry"
        else:
            return "neutral"

API Integrations

FunBot integrates with these free APIs:

  • Joke APIs: Official Joke API, JokeAPI, icanhazdadjoke
  • Fact APIs: Useless Facts API, Cat Facts API, Dog Facts API, Numbers API

All APIs are free to use and don't require API keys for basic usage.
